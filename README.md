# VAELIA · Vístete para ti.

## Requisitos

- Node.js 26
- MySQL 8 o TiDB Cloud

## Instalación

```bash
npm install
cp .env.example .env     # completa las variables
npm run db:setup         # crea las tablas y carga los datos de ejemplo
npm run dev              # inicia el servidor
```

Abre **http://localhost:3000**
